# Contract Ownership

`AI-Frontend-Experience` does not own backend or design contracts. It owns:

- generated web client bindings
- local compatibility declarations
- route and component implementation that must remain compatible with upstream design handoffs

## Upstream owners

- `AI-Software-Factory`: Software Factory API contracts
- `AI Platform Automation`: Platform Automation API contracts
- `Design-Factory_Figma`: route maps, component specs, state maps, and tokens
- `Design Factory_Stitch`: concept inventories and exploratory prompt outputs
