# Repository Map

## Apps

- `apps/software-factory-web`: work items, builds, agents, API explorer, authenticated shell.
- `apps/platform-automation-web`: clusters, workspaces, promises, GraphQL explorer, API explorer.
- `apps/docs-portal`: getting started, architecture summary, runbooks, and integration docs.

## Packages

- `packages/design-tokens`: token schema, CSS variable generation, Tailwind-ready theme data.
- `packages/ui`: cards, badges, tables, headers, and the BAC app shell.
- `packages/api-clients`: transport helpers, mocks, and page-facing data functions.
- `packages/auth`: cookie-backed session model and role guards.
- `packages/config`: runtime validation and region mappings.
- `packages/observability`: logger and tracing helpers.
- `packages/testing`: test fixtures, provider helpers, and MSW handlers.

## Tooling

- `scripts/`: repo sync and clean scripts.
- `.github/workflows/`: PR, push, and release foundations.
